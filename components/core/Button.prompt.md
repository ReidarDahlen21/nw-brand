Pill-shaped CTA button in Nucleo Wealth's champagne/navy palette; use for primary actions, forms, and dashboard CTAs.

```jsx
<Button variant="primary" size="md">Solicitar diagnóstico</Button>
```

Variants: `primary` (champagne fill, navy text — main CTA), `secondary` (outlined, navy text — on hueso bg), `ghost` (borderless), `on-dark` (outlined hueso text — use on navy backgrounds). Sizes: `sm` `md` `lg`. `disabled` dims to 45% opacity.
